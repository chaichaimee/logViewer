LogViewer


Находите, отмечайте, копируйте — полный контроль над журналом NVDA.


Автор: chai chaimee & Pierre-Louis R.

URL: https://github.com/chaichaimee/logViewer


Введение


LogViewer — это дополнение для NVDA, которое превращает просмотрщик журнала NVDA и даже файл журнала, открытый во внешнем текстовом редакторе, в полноценное рабочее пространство с поддержкой поиска и закладок.


Вместо бесконечной прокрутки тысяч строк журнала в поисках ошибки вы можете мгновенно выполнять поиск, переходить к любой закладке и копировать весь блок ошибки в буфер обмена одним дополнительным нажатием клавиши.


Оно также автоматически отслеживает сбои: если NVDA перезапустилась после сбоя, LogViewer незаметно ставит закладку в месте сбоя в старом журнале, чтобы вы могли сразу найти его.


Горячие клавиши

Control+F
Одиночное нажатие : Открыть диалог «Поиск в журнале NVDA» (работает только при фокусе в Просмотрщике журнала NVDA)
Control+F2
Одиночное нажатие : Вставить нумерованную закладку в текущей позиции журнала
F2
Одиночное нажатие : Перейти к следующей закладке в журнале
Shift+F2
Одиночное нажатие : Перейти к предыдущей закладке в журнале
F3
Одиночное нажатие : Найти следующее совпадение текущего термина быстрого поиска
Двойное нажатие : Скопировать блок ERROR / WARNING / Traceback для текущего совпадения в буфер обмена
Shift+F3
Одиночное нажатие : Найти предыдущее совпадение текущего термина быстрого поиска
NVDA+Control+L
Одиночное нажатие : Открыть файл журнала NVDA в текстовом редакторе по умолчанию (предпочитает nvda-old.log, при отсутствии использует nvda.log)
Control+Shift+F2
Одиночное нажатие : Скопировать в буфер обмена всё, что было записано после последней закладки
Двойное нажатие : Сделать шаг назад и скопировать сегмент, относящийся к предыдущей закладке
Тройное нажатие : Переключить источник чтения между текущим журналом и старым журналом для этой функции

Возможности


Диалог поиска (Control+F)

При фокусе в Просмотрщике журнала NVDA комбинация Control+F открывает специальный диалог поиска с:


- Полем поиска, которое запоминает ваши последние 20 поисковых запросов.
- Флажком С учётом регистра.
- Флажком Зациклить поиск, чтобы поиск продолжался с начала/конца, а не останавливался в конце файла.
- Выбором между поиском по обычному тексту и регулярному выражению.
- Кнопками Найти далее и Найти ранее для перемещения по совпадениям без закрытия диалога.
- Кнопкой Найти и перейти (или нажатием Enter в поле поиска), которая закрывает диалог и перемещает курсор непосредственно к совпадению в журнале.
- Окном результатов, которое показывает несколько совпадений вокруг вашей текущей позиции, отмечая активное.


Сам поиск выполняется в фоновом потоке, поэтому очень большие журналы не замедляют и не замораживают NVDA во время сканирования.


Закладки (Control+F2, F2, Shift+F2)

Control+F2 записывает строку вида BOOKMARK 3 в текущей позиции журнала и проговаривает номер закладки. Каждая новая закладка автоматически увеличивает номер на единицу.


F2 и Shift+F2 позволяют перемещаться вперёд или назад между этими закладками. Если в настройках включен Зациклить поиск, при достижении последней закладки происходит переход к первой, и наоборот.


Пошагово при нажатии F2:


1. LogViewer повторно сканирует текст журнала на наличие всех маркеров BOOKMARK и сортирует их по позиции.
2. Он перемещается на одну позицию вперёд в этом отсортированном списке.
3. Если вы уже находились на последней закладке, а зацикливание отключено, вы услышите «Достигнут конец закладок» и останетесь на месте.
4. В противном случае ваш курсор перемещается к этой закладке, и NVDA объявляет её номер.


Сам счётчик закладок автоматически сбрасывается на 1 при полной перезагрузке Windows (определяется по времени работы системы), но сохраняется при обычных перезапусках NVDA.


Автоматическая закладка при сбое

При запуске LogViewer проверяет журнал предыдущей сессии (nvda-old.log) на наличие признаков сбоя NVDA, таких как Traceback, необработанное исключение или запись CRASH в самой последней строке.


Если сбой обнаружен и закладка рядом с ним ещё не была поставлена, LogViewer незаметно добавляет закладку в этот старый журнал, чтобы вы могли сразу найти место сбоя с помощью F2/Shift+F2 без ручного поиска.


Быстрый поиск и копирование блока ошибки (F3 / Shift+F3)

F3 выполняет быстрый поиск без диалога с использованием последнего поискового запроса или, если поиск ещё не производился, одного из настроенных терминов по умолчанию (см. Настройки ниже).


Клавиша F3 также имеет двойное действие:


- Одиночное нажатие: перейти к следующему совпадению и объявить его (точный формат объявления зависит от ваших настроек).
- Двойное нажатие (в течение полусекунды): вместо перемещения LogViewer копирует весь блок ошибки/предупреждения/traceback вокруг текущего совпадения в буфер обмена и воспроизводит короткий звуковой сигнал для подтверждения.


Как определяется «блок», пошагово:


1. LogViewer ищет вверх от совпадения, чтобы найти начало блока, распознавая строки, начинающиеся с "ERROR -", "WARNING -" или "Traceback".
2. Затем он ищет вниз, включая любые строки с отступом, относящиеся к этому же блоку (например, строки traceback в Python).
3. Он останавливается на следующей строке INFO/WARNING/ERROR/DEBUG, пустой строке или строке без отступа, в зависимости от того, что встретится раньше.
4. Копируется только полученный блок текста, а не весь журнал.


Shift+F3 всегда выполняет обычный поиск предыдущего совпадения с тем же последним запросом и никогда не запускает копирование.


Открыть файл журнала (NVDA+Control+L)

Это открывает журнал NVDA в текстовом редакторе по умолчанию вашей системы. Предпочтение отдаётся nvda-old.log (журнал предыдущей сессии, наиболее полезный сразу после сбоя или перезапуска), с переходом на nvda.log, если старый журнал отсутствует.


После открытия таким способом LogViewer запоминает, какой файл вы открыли, поэтому F2, Shift+F2 и горячие клавиши поиска продолжают работать, даже когда ваш курсор находится внутри окна этого внешнего редактора, а не только во встроенном Просмотрщике журнала NVDA.


Копировать от закладки (Control+Shift+F2)

Эта горячая клавиша читает закладки непосредственно из файла журнала на диске, поэтому работает, даже если не открыты ни Просмотрщик журнала NVDA, ни внешний редактор. Она имеет три уровня нажатия:


- Одиночное нажатие: копирует всё, что записано после самой последней закладки, в буфер обмена.
- Двойное нажатие: шагает ещё на одну закладку назад и копирует этот более ранний сегмент; повторное нажатие перемещает вас назад по истории закладок, возвращаясь к самой последней после прохождения первой.
- Тройное нажатие: переключает файл журнала, из которого читает эта функция, между nvda.log текущей сессии и nvda-old.log предыдущей сессии.


Каждое успешное копирование сопровождается коротким подтверждающим звуковым сигналом.


Учёт конфликтующих приложений

Некоторые приложения используют Control+F2 или Control+Shift+F2 для собственных целей. LogViewer проверяет текущее приложение (например, Notepad++, Word, VS Code, Sublime Text, Atom или Brackets) и, если оно совпадает с одним из них, передаёт нажатие клавиши напрямую этому приложению вместо перехвата.


Панель настроек

В диалог настроек NVDA добавляется категория «Просмотрщик журнала», предлагающая:


- Флажки С учётом регистра по умолчанию и Зацикливать поиск по умолчанию, соответствующие опциям самого диалога поиска.
- Стиль объявления результатов поиска: выбор между чтением результатов как термин, номер строки и позиция совпадения вместе; только номер строки; или только текст найденной строки.
- Термины быстрого поиска по умолчанию: список (по одному на строку) терминов, к которым F3 автоматически обращается, если ручной поиск ещё не производился.


Все настройки вместе с историей поисковых запросов хранятся в виде JSON-файлов в папке пользовательской конфигурации NVDA, и LogViewer автоматически переносят данные, сохранённые старыми версиями дополнения, в это место.
