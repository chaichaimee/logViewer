LogViewer


ค้นหา บุ๊กมาร์ก คัดลอก — ควบคุมบันทึกข้อความ NVDA ได้อย่างสมบูรณ์แบบ


ผู้พัฒนา: chai chaimee & Pierre-Louis R.

url: https://github.com/chaichaimee/logViewer


บทนำ


LogViewer คือแอพพลิเคชันเสริมสำหรับ NVDA ที่เปลี่ยนหน้าต่างเครื่องมือดูบันทึกข้อความ (Log Viewer) รวมถึงไฟล์ Log ที่เปิดด้วยโปรแกรมแก้ไขข้อความภายนอก ให้กลายเป็นพื้นที่ทำงานที่สามารถค้นหาและทำบุ๊กมาร์กได้อย่างเต็มรูปแบบ


แทนที่จะต้องเลื่อนหน้าจอหาข้อผิดพลาดท่ามกลางบรรทัด Log นับพันอย่างไม่รู้จบ คุณสามารถค้นหาได้ทันที กระโดดไปยังบุ๊กมาร์กที่ต้องการ และคัดลอกบล็อกข้อผิดพลาดทั้งหมดไปยังคลิปบอร์ดได้ด้วยการกดปุ่มเพิ่มอีกเพียงครั้งเดียว


นอกจากนี้ ยังมีระบบตรวจจับการล่ม/ค้างอัตโนมัติ: หาก NVDA เริ่มทำงานใหม่หลังจากการล่ม LogViewer จะวางบุ๊กมาร์กไว้ที่จุดเกิดปัญหาใน Log เก่าอย่างเงียบๆ เพื่อให้คุณค้นหาจุดที่มีปัญหาได้ในทันที


ปุ่มลัด (Hot Keys)

Control+F
กดหนึ่งครั้ง : เปิดไดอะล็อกค้นหาใน NVDA Log (ใช้งานได้เฉพาะขณะโฟกัสอยู่ในหน้าต่าง NVDA Log Viewer)
Control+F2
กดหนึ่งครั้ง : แทรกบุ๊กมาร์กแบบระบุหมายเลข ณ ตำแหน่งปัจจุบันใน Log
F2
กดหนึ่งครั้ง : เลื่อนไปยังบุ๊กมาร์กถัดไปใน Log
Shift+F2
กดหนึ่งครั้ง : เลื่อนไปยังบุ๊กมาร์กก่อนหน้าใน Log
F3
กดหนึ่งครั้ง : ค้นหาข้อความถัดไปของคำค้นหาด่วนปัจจุบัน
กดสองครั้ง : คัดลอกบล็อก ERROR / WARNING / Traceback ณ ตำแหน่งที่ค้นพบไปยังคลิปบอร์ด
Shift+F3
กดหนึ่งครั้ง : ค้นหาข้อความก่อนหน้าของคำค้นหาด่วนปัจจุบัน
NVDA+Control+L
กดหนึ่งครั้ง : เปิดไฟล์ NVDA Log ด้วยโปรแกรมแก้ไขข้อความเริ่มต้นของคุณ (จะเลือกเปิด nvda-old.log ก่อน หากไม่มีจะเปิด nvda.log)
Control+Shift+F2
กดหนึ่งครั้ง : คัดลอกข้อความ Log ทั้งหมดตั้งแต่บุ๊กมาร์กล่าสุดไปยังคลิปบอร์ด
กดสองครั้ง : ย้อนกลับไปหนึ่งบุ๊กมาร์กและคัดลอกข้อความในส่วนของบุ๊กมาร์กก่อนหน้าแทน
กดสามครั้ง : สลับการอ่านไฟล์ Log ระหว่าง Log ปัจจุบันกับ Log เก่าสำหรับคุณสมบัตินี้

คุณสมบัติเด่น


ไดอะล็อกค้นหา (Control+F)

ขณะโฟกัสอยู่ใน NVDA Log Viewer การกด Control+F จะเปิดไดอะล็อกค้นหาเฉพาะซึ่งประกอบด้วย:


- ช่องค้นหาที่จดจำคำค้นหาล่าสุดของคุณได้สูงสุด 20 คำ
- ช่องทำเครื่องหมาย ตรงตามตัวพิมพ์ใหญ่-เล็ก (Case sensitive)
- ช่องทำเครื่องหมาย ค้นหาแบบวนรอบ (Wrap around) เพื่อให้การค้นหาดำเนินการต่อจากบนสุด/ล่างสุดแทนที่จะหยุดเมื่อถึงจุดสิ้นสุด
- ตัวเลือกระหว่างการค้นหาด้วย ข้อความธรรมดา (normal text) หรือ นิพจน์เรกิวลาร์ (regular expression)
- ปุ่ม หาถัดไป (Find Next) และ หาก่อนหน้า (Find Previous) เพื่อเลื่อนดูผลลัพธ์โดยที่ไดอะล็อกยังคงเปิดอยู่
- ปุ่ม ค้นหา & โฟกัส (Find & Focus) (หรือการกด Enter ในช่องค้นหา) ซึ่งจะปิดไดอะล็อกและย้ายเคอร์เซอร์ของคุณไปยังตำแหน่งที่พบใน Log โดยตรง
- กล่องแสดงผลลัพธ์ที่แสดงตัวอย่างผลลัพธ์รอบๆ ตำแหน่งปัจจุบันของคุณ พร้อมทำเครื่องหมายตำแหน่งที่ใช้งานอยู่


ตัวระบบค้นหาทำงานบนเธรดเบื้องหลัง (Background thread) ทำให้ไฟล์ Log ขนาดใหญ่ไม่ส่งผลให้ NVDA ช้าลงหรือค้างขณะกำลังสแกน


บุ๊กมาร์ก (Control+F2, F2, Shift+F2)

Control+F2 จะเขียนบรรทัด เช่น BOOKMARK 3 ลงใน Log ณ ตำแหน่งปัจจุบันของคุณและอ่านหมายเลขบุ๊กมาร์กออกเสียง ทุกๆ บุ๊กมาร์กใหม่จะเพิ่มหมายเลขขึ้นทีละหนึ่งโดยอัตโนมัติ


จากนั้น F2 และ Shift+F2 จะช่วยให้คุณกระโดดข้ามไปข้างหน้าหรือย้อนกลับระหว่างบุ๊กมาร์กเหล่านี้ได้ หากเปิดใช้งาน ค้นหาแบบวนรอบ (Wrap around) ในการตั้งค่า เมื่อไปถึงบุ๊กมาร์กสุดท้ายจะวนกลับมายังบุ๊กมาร์กแรก และในทางกลับกัน


ขั้นตอนการทำงานเมื่อคุณกด F2:


1. LogViewer จะสแกนข้อความใน Log ใหม่เพื่อหาเครื่องหมาย BOOKMARK ทั้งหมดและเรียงลำดับตามตำแหน่ง
2. เลื่อนไปยังตำแหน่งถัดไปในรายการที่เรียงลำดับไว้นั้น
3. หากคุณอยู่ที่บุ๊กมาร์กสุดท้ายแล้วและปิดการวนรอบไว้ คุณจะได้ยินเสียงแจ้งเตือน "ถึงจุดสิ้นสุดของบุ๊กมาร์กแล้ว" และเคอร์เซอร์จะอยู่ที่เดิม
4. หากไม่ใช่ เคอร์เซอร์จะถูกย้ายไปยังตำแหน่งของบุ๊กมาร์กนั้นและ NVDA จะอ่านประกาศหมายเลขบุ๊กมาร์ก


ตัวนับบุ๊กมาร์กจะรีเซ็ตกลับเป็น 1 โดยอัตโนมัติเมื่อมีการรีสตาร์ต Windows ใหม่ทั้งหมด (ตรวจจับผ่านเวลาการทำงานของระบบ) แต่จะคงค่าเดิมไว้หากเป็นการรีสตาร์ต NVDA ตามปกติ


สร้างบุ๊กมาร์กอัตโนมัติเมื่อโปรแกรมล่ม

เมื่อเริ่มต้นทำงาน LogViewer จะตรวจสอบ Log ของเซสชันก่อนหน้า (nvda-old.log) เพื่อหาร่องรอยการล่มของ NVDA เช่น Traceback, ข้อยกเว้นที่ไม่ได้รับการจัดการ (unhandled exception) หรือรายการ CRASH ในบรรทัดสุดท้าย


หากตรวจพบการล่มและยังไม่มีบุ๊กมาร์กถูกวางไว้ใกล้จุดนั้น LogViewer จะต่อท้ายบุ๊กมาร์กลงใน Log เก่านั้นอย่างเงียบๆ เพื่อให้คุณค้นหาจุดที่เกิดการล่มได้ทันทีด้วย F2/Shift+F2 โดยไม่ต้องค้นหาด้วยตนเอง


ค้นหาอย่างเร็วและคัดลอกบล็อกข้อผิดพลาด (F3 / Shift+F3)

F3 จะทำการค้นหาอย่างเร็วโดยไม่ต้องเปิดไดอะล็อก โดยใช้คำค้นหาล่าสุด หรือหากยังไม่มีการค้นหา จะใช้คำค้นหาด่วนเริ่มต้นที่คุณกำหนดไว้ (ดูการตั้งค่าด้านล่าง)


F3 ยังเป็นปุ่มที่ทำงานได้สองรูปแบบ:


- กดหนึ่งครั้ง: กระโดดไปยังผลลัพธ์ถัดไปและอ่านออกเสียง (รูปแบบการอ่านออกเสียงที่แน่นอนขึ้นอยู่กับการตั้งค่าของคุณ)
- กดสองครั้ง (ภายในครึ่งวินาที): แทนที่จะย้ายเคอร์เซอร์ LogViewer จะคัดลอกบล็อกข้อผิดพลาด/คำเตือน/traceback ทั้งหมดที่ล้อมรอบผลลัพธ์ปัจจุบันไปยังคลิปบอร์ด และส่งเสียงบี๊บสั้นๆ เพื่อยืนยันการคัดลอก


ขั้นตอนการตรวจจับ "บล็อก" ข้อผิดพลาด:


1. LogViewer จะมองขึ้นไปด้านบนจากจุดที่พบเพื่อหาจุดเริ่มต้นของบล็อก โดยตรวจสอบบรรทัดที่ขึ้นต้นด้วย "ERROR -", "WARNING -" หรือ "Traceback"
2. จากนั้นจะมองลงไปด้านล่าง รวมถึงบรรทัดที่มีการย่อหน้าต่อเนื่องซึ่งเป็นของบล็อกเดียวกัน (เช่น บรรทัดของ Python traceback)
3. จะหยุดเมื่อเจอบรรทัด INFO/WARNING/ERROR/DEBUG ถัดไป บรรทัดว่าง หรือบรรทัดที่ไม่มีย่อหน้า แล้วแต่ว่าจะเจอสิ่งใดก่อน
4. ระบบจะคัดลอกเฉพาะบล็อกข้อความที่ได้เท่านั้น — ไม่ได้คัดลอก Log ทั้งหมด


Shift+F3 จะทำการค้นหาข้อความก่อนหน้าแบบธรรมดาโดยใช้คำค้นหาล่าสุดเดียวกันเสมอ และจะไม่เปิดทำงานฟังก์ชันการคัดลอก


เปิดไฟล์บันทึกข้อความ (NVDA+Control+L)

การกดปุ่มนี้จะเปิด NVDA Log ในโปรแกรมแก้ไขข้อความเริ่มต้นของระบบ โดยจะเลือกเปิด nvda-old.log (Log ของเซสชันก่อนหน้า ซึ่งมีประโยชน์ที่สุดหลังจากการล่มหรือรีสตาร์ต) และจะสลับไปเปิด nvda.log หากไม่มี Log เก่าอยู่


เมื่อเปิดด้วยวิธีนี้แล้ว LogViewer จะจดจำไฟล์ที่คุณเปิดไว้ เพื่อให้ปุ่ม F2, Shift+F2 และปุ่มลัดค้นหายังคงทำงานได้ แม้ว่าเคอร์เซอร์ของคุณจะอยู่ในหน้าต่างโปรแกรมแก้ไขข้อความภายนอกก็ตาม ไม่ใช่แค่ใน NVDA Log Viewer ที่บิวต์อินมาเท่านั้น


คัดลอกหลังจากบุ๊กมาร์ก (Control+Shift+F2)

ปุ่มลัดนี้จะอ่านบุ๊กมาร์กโดยตรงจากไฟล์ Log บนดิสก์ จึงทำงานได้แม้ว่าจะไม่ได้เปิด NVDA Log Viewer หรือโปรแกรมแก้ไขข้อความภายนอกอยู่ก็ตาม ปุ่มนี้มีการกด 3 ระดับ:


- กดหนึ่งครั้ง: คัดลอกข้อความ Log ทั้งหมดที่บันทึกไว้หลังจากบุ๊กมาร์กล่าสุดไปยังคลิปบอร์ด
- กดสองครั้ง: ถอยหลังไปอีกหนึ่งบุ๊กมาร์กและคัดลอกส่วนก่อนหน้านั้นแทน — การกดซ้ำๆ จะเป็นการย้อนประวัติบุ๊กมาร์กถอยหลังไปเรื่อยๆ และจะวนกลับมายังบุ๊กมาร์กล่าสุดเมื่อผ่านบุ๊กมาร์กแรกไปแล้ว
- กดสามครั้ง: สลับไฟล์ Log ที่คุณสมบัตินี้ใช้อ่าน ระหว่าง nvda.log ของเซสชันปัจจุบัน และ nvda-old.log ของเซสชันก่อนหน้า


การคัดลอกที่สำเร็จแต่ละครั้งจะมีเสียงบี๊บสั้นๆ ยืนยัน


การตรวจจับแอปพลิเคชันที่ใช้ปุ่มลัดซ้ำกัน

บางแอปพลิเคชันใช้ Control+F2 หรือ Control+Shift+F2 เพื่อวัตถุประสงค์ของตนเอง LogViewer จะตรวจสอบแอปพลิเคชันปัจจุบัน (เช่น Notepad++, Word, VS Code, Sublime Text, Atom หรือ Brackets) และหากตรงกับหนึ่งในแอปเหล่านี้ จะส่งผ่านการกดปุ่มไปยังแอปพลิเคชันนั้นโดยตรงแทนที่จะดักจับไว้


แผงการตั้งค่า

หมวดหมู่ "เครื่องมือดูบันทึกข้อความ (Log Viewer)" จะถูกเพิ่มเข้าไปในไดอะล็อกการตั้งค่าของ NVDA ซึ่งมีตัวเลือกดังนี้:


- ช่องทำเครื่องหมาย ตรงตามตัวพิมพ์ใหญ่-เล็กเป็นค่าเริ่มต้น และ ค้นหาแบบวนรอบเป็นค่าเริ่มต้น ซึ่งตรงกับตัวเลือกในไดอะล็อกค้นหา
- รูปแบบการอ่านแจ้งผลลัพธ์การค้นหา เลือกได้ว่าจะให้อ่านผลลัพธ์เป็นคำค้นหา หมายเลขบรรทัด และตำแหน่งที่พบร่วมกัน, อ่านเฉพาะหมายเลขบรรทัด หรืออ่านเฉพาะข้อความในบรรทัดที่พบ
- คำค้นหาด่วนเริ่มต้น รายการคำค้นหา (หนึ่งคำต่อบรรทัด) ที่ F3 จะดึงมาใช้โดยอัตโนมัติเมื่อยังไม่มีการค้นหาด้วยตนเอง


การตั้งค่าทั้งหมดพร้อมกับประวัติคำค้นหาของคุณจะถูกจัดเก็บเป็นไฟล์ JSON ไว้ในโฟลเดอร์การกำหนดค่าผู้ใช้ของ NVDA และ LogViewer จะย้ายข้อมูลที่บันทึกไว้โดยแอดออนเวอร์ชันเก่ามายังตำแหน่งนี้โดยอัตโนมัติ



สนับสนุนผู้พัฒนา

หากเครื่องมือนี้ช่วยให้ชีวิตของคุณง่ายขึ้น ร่วมเป็นส่วนหนึ่งในการสนับสนุนการอัปเดตครั้งถัดไปได้ด้วยการบริจาคเล็กๆ น้อยๆ



การสนับสนุนของคุณมีความหมายอย่างยิ่ง มาสร้างสรรค์สิ่งดีๆ ร่วมกันครับ
